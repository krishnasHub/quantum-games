# Quantum Games

**Play online:** https://krishnashub.github.io/quantum-games/

Small browser games built on real quantum mechanics: the uncertainty principle, measurement and collapse, tunnelling, interference, the quantum Zeno effect and entanglement.

## Games

| Game | Description |
| --- | --- |
| [Collapse](collapse/) | A puzzle game on a real Schrödinger simulation. Place mirrors, walls and watchers to steer a wave into the exit, using tunnelling, the uncertainty principle and the quantum Zeno effect. Open `collapse/index.html` to play. |

![Collapse: The Long Way](collapse/screenshots/the-long-way.png)

Each game is a single HTML file with no build step, so it runs straight from GitHub Pages. The root `index.html` is the landing page. [DESIGN.md](DESIGN.md) has the design for Collapse and for the games planned next (Dark Port and Spooky Action).
